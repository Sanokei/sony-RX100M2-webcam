# Third-party components

- **UnityCaptureFilter64.dll** is a prebuilt build of [UnityCapture](https://github.com/schellingb/UnityCapture) by Ben Schelling (MIT license). The license text is in that repository.
- **ESPCN_x2.pb** is the 2x ESPCN super-resolution model from [TF-ESPCN](https://github.com/fannymonori/TF-ESPCN).
- Python packages bundled in releases: OpenCV (Apache-2.0), NumPy (BSD), pyvirtualcam (GPL-2.0).
